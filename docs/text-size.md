# Text size

Change how large text is in Zeni. The choice applies to the whole app and is saved on this computer.

In **Settings > Text size**, pick 90%, 100% (default), 115%, 130% or 150%.

Shortcuts:

- Ctrl+= or Ctrl++: bigger
- Ctrl+-: smaller
- Ctrl+0: back to 100%

Each shortcut moves one step along the list above and saves the result.
